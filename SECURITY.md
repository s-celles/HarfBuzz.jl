# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in HarfBuzz.jl, please report
it responsibly via a **GitHub Security Advisory**:

- Go to <https://github.com/s-celles/HarfBuzz.jl/security/advisories/new>
  and click **"Report a vulnerability"**.
- **Do not** open a public GitHub issue.
- Include a description of the issue, a proof of concept, and the
  affected versions.

You should receive an acknowledgement within a few days. Please allow
reasonable time for investigation and a fix before any public
disclosure.

## Scope

This policy covers the Julia wrapper `HarfBuzz.jl` only. Vulnerabilities
in upstream [HarfBuzz](https://harfbuzz.github.io/) should be reported
through the upstream project's channels.

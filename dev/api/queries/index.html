Font size and metrics state

scale, ppem and ptem each have a setter suffixed with ! (scale!, ppem!, ptem!).

HarfBuzz.scale — Function
scale(font::Font) -> Tuple{Int,Int}
scale!(font::Font, (x, y))

Get or set the horizontal and vertical scale, in font units. Shaping output is expressed in these units.

source
HarfBuzz.ppem — Function
ppem(font::Font) -> Tuple{Int,Int}
ppem!(font::Font, (x, y))

Get or set the horizontal and vertical pixels-per-em, used by fonts that carry bitmap strikes or size-specific hinting.

source
HarfBuzz.ptem — Function
ptem(font::Font) -> Float64
ptem!(font::Font, points)

Get or set the point size, which fonts with an optical size axis use to pick an optical variant. Zero means unset.

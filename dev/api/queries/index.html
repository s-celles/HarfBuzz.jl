HarfBuzz.GlyphExtents — Type
GlyphExtents

Bounding box of a glyph, in the font's scale units. y grows upward, so a cap-height glyph has a positive y_bearing and a negative height.

  • x_bearing, y_bearing — top-left corner relative to the origin.
  • width, height — extent from that corner.
source
HarfBuzz.FontExtents — Type
FontExtents

Line metrics, in the font's scale units.

  • ascender — distance above the baseline, positive.
  • descender — distance below it, negative.
  • line_gap — extra leading between lines.

OpenType metrics and style

HarfBuzz.metric — Function
metric(font::Font, name::Symbol; fallback = true) -> Union{Int32,Nothing}

An OpenType metric such as :x_height, :cap_height, :underline_offset or :strikeout_size, in the font's scale units.

With fallback = true HarfBuzz synthesises a value when the font carries none; with fallback = false a missing metric returns nothing.

Available: :horizontalascender, :horizontaldescender, :horizontallinegap, :horizontalclippingascent, :horizontalclippingdescent, :verticalascender, :verticaldescender, :verticallinegap, :horizontalcaretrise, :horizontalcaretrun, :horizontalcaretoffset, :verticalcaretrise, :verticalcaretrun, :verticalcaretoffset, :xheight, :capheight, :subscriptemxsize, :subscriptemysize, :subscriptemxoffset, :subscriptemyoffset, :superscriptemxsize, :superscriptemysize, :superscriptemxoffset, :superscriptemyoffset, :strikeoutsize, :strikeoutoffset, :underlinesize, :underlineoffset.

source
HarfBuzz.style — Function
style(font::Font, name::Symbol) -> Float64

A style value: :weight (100–900), :width (a percentage), :italic (0 or 1), :slant_angle in degrees, :slant_ratio, or :optical_size in points. Reflects any variation set on the font.

HarfBuzz.outline — Function
outline(font::Font, glyph) -> Vector{PathCommand}

The glyph's outline as a list of path commands. Empty for a glyph that draws nothing, such as a space.

for cmd in outline(font, gid)
    cmd.op === :line_to && println(cmd.points[1])
end
source
HarfBuzz.draw_glyph — Function
draw_glyph(f, font::Font, glyph)

Walk a glyph's outline, calling f(op, points) for each step. op is :move_to, :line_to, :quadratic_to, :cubic_to or :close_path, and points are in the font's scale units.

draw_glyph(font, gid) do op, points
    op === :move_to && move(points[1]...)
end
source
HarfBuzz.PathCommand — Type
PathCommand

One step of a glyph outline: an op (:move_to, :line_to, :quadratic_to, :cubic_to or :close_path) and its control points, in the font's scale units.

:quadratic_to carries one control point then the endpoint; :cubic_to two control points then the endpoint; :close_path none.

Subsetting

HarfBuzz.subset — Function
subset(face::Face; unicodes = nothing, glyphs = nothing,
       flags = Symbol[]) -> Face

Cut a face down to the codepoints or glyphs given, returning a new face backed by freshly generated font data.

Flags: :nohinting, :retaingids, :desubroutinize, :namelegacy, :setoverlapsflag, :passthroughunrecognized, :notdefoutline, :glyphnames, :nopruneunicoderanges, :nolayoutclosure, :optimizeiupdeltas. `:glyphnamesis worth knowing about — without it theposttable's glyph names are dropped, so [glyph_name](@ref) returnsnothing` on the result.

small = subset(face; unicodes = UInt32.(collect("Hello")))
write("hello.ttf", data(small._blob))
